# Road Rash

A modern remake of the legendary bike racing game from the DOS era, built with TypeScript and rendered using HTML5 Canvas.

## Description

This project is a tribute to the classic game Road Rash. It aims to recreate the thrilling experience of high-speed motorcycle racing combined with combat. Race against opponents, kick and punch them to take the lead, and try to finish the race without wiping out.

## Features

- Endless road generation with curves and hills
- Player and opponent characters with animations
- Bike combat: punch and kick your opponents
- Collision detection with roadside objects and other racers
- Basic physics for player and opponent movement

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) and [npm](https://www.npmjs.com/)

### Installation and Running

1.  Clone the repository:
    ```bash
    git clone https://github.com/roopeshchinnakampalli/roadrash.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd roadrash
    ```
3.  Install the dependencies:
    ```bash
    npm install
    ```
4.  Start the development server:
    ```bash
    npm start
    ```
    This will open the game in your default browser.

### Building for Production

To create a production build, run:

```bash
npm run build
```

This will generate a `dist` folder with the bundled application.

## How to Play



-   **Accelerate:** Up Arrow

-   **Brake:** Down Arrow

-   **Steer Left:** Left Arrow

-   **Steer Right:** Right Arrow

-   **Punch:** A

-   **Kick:** S
